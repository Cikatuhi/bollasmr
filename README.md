# BallPlay

Браузерная площадка для пользовательских физических симуляций в вертикальном формате. Текущий режим — слияние загруженных PNG-объектов 9:16 на React, TypeScript, PixiJS, Matter.js и Web Audio API.

## Локальный запуск

Нужны Node.js 20.19+ (или 22.12+) и pnpm.

```bash
pnpm install
pnpm dev
```

Vite покажет локальный адрес. Проверки и production-сборка:

```bash
pnpm test
pnpm build
pnpm preview
```

## Что работает

- Гравитация Matter.js, упругость и столкновения объектов со стенами и друг с другом; размер, масса, скорость симуляции и физические настройки обновляются на лету.
- Адаптивный холст PixiJS 360 × 640 (9:16), выбор объектов мышью, перетаскивание и бросок.
- Пользовательская сцена открывается пустой: демо-шары и примитивы не создаются. Загруженные PNG автоматически появляются в арене, сохраняются в IndexedDB и восстанавливаются при повторном открытии выбранной коллекции.
- Изображения сохраняют пропорции, а физическая оболочка — круглая, с размером и массой из настроек уровня. Повторный экземпляр можно добавить кнопкой «Ещё объект» для проверки слияния.
- Web Audio только для успешного слияния: звук столкновений шаров и ударов о стены отключён. Для каждого перехода уровня можно загрузить отдельный файл, прослушать его, заменить, удалить и настроить громкость; одновременно звучит не более пяти сэмплов.
- Список слоёв и жёсткий лимит 150 объектов на сцену.
- Коллекции пользовательских PNG в разделе «Коллекции объектов»: уровни, размер, масса, миниатюры, автоматическое добавление/замена в сцене и удаление.
- Слияние двух объектов одной коллекции и уровня в следующий уровень выполняется после шага Matter.js; разные коллекции/уровни не сливаются.
- Отдельные переходные звуки `L1 → L2`, `L2 → L3` и т. д. с громкостью, прослушиванием, заменой и удалением.
- PNG и аудио сохраняются как Blob в IndexedDB и восстанавливаются после перезагрузки (при недоступном IndexedDB используется временный MemoryStore).

Экспорт видео, аккаунты, серверное сохранение, спирали, лабиринты, разрушение и размножение объектов пока не входят в основу.

## Структура

```text
src/
  audio/       Web Audio для переходных звуков слияния и лимит одновременных сэмплов
  components/  Окно симуляции с PixiJS
  objects/     Расширяемые описания и шаблоны объектов
  physics/     Сцена Matter.js, фабрики тел и тесты
  collections/ IndexedDB-хранилище коллекций, PNG и transition sounds
  rendering/   Отрисовка сцены PixiJS
  App.tsx      Компоновка редактора и связь настроек
  styles.css   Тёмный адаптивный интерфейс
```

Состояние Matter.js и PixiJS хранится вне состояния React. Окно симуляции владеет движком, Pixi-приложением, обработчиками указателя и наблюдателем размера и освобождает их при размонтировании.

Физические оболочки создаются через `registerPhysicsBodyFactory()` из `src/physics/bodyFactories.ts`. Чтобы добавить новый тип без изменений шага симуляции, столкновений и жизненного цикла, зарегистрируй шаблон и фабрику (и расширь `ObjectKindMap` через module augmentation для TypeScript). Визуально новый тип может переиспользовать круг, многоугольник, изображение или прямоугольник через поле `visual`.

## Как проверить merge-механику вручную

1. Запусти `pnpm dev` и открой адрес Vite (обычно `http://localhost:5173`). Если порт занят, используй `pnpm exec vite --host 0.0.0.0 --port 5174`.
2. В правой панели «Коллекции объектов» создай коллекцию и загрузи PNG для уровня 1. Картинка появится в сцене автоматически. Добавь уровень 2 и загрузи его PNG. При необходимости загрузи звук в строке «Переход L1 → L2» и нажми кнопку с именем файла для прослушивания. Обычные столкновения звука не вызывают.
3. Добавь ещё один экземпляр уровня 1 кнопкой «Ещё объект». Два одинаковых изображения столкнутся и объединятся в объект уровня 2; исходные тела исчезнут. В списке «Слои» останется новый объект.
4. Останови/запусти сцену кнопкой «Пауза», измени гравитацию, упругость и скорость. Слияние должно работать при любых этих значениях.
5. Чтобы загрузить ещё один тип объекта, создай другую коллекцию и выбери её. Сцена переключится на PNG выбранной коллекции; разные коллекции/уровни не сливаются. Если следующего уровня нет, два объекта останутся в сцене без transition sound.
6. Перезагрузи страницу. Название коллекции, уровни, миниатюры и по одному экземпляру каждого загруженного уровня выбранной коллекции восстановятся из IndexedDB. Бинарные данные не записываются в localStorage.

Автоматические проверки:

```bash
pnpm test   # физика, merge-дедупликация и persistence-модель
pnpm build  # TypeScript + production bundle
```

Для аудио нужен пользовательский жест браузера: нажми «Проверить» или «В сцену», после чего Web Audio снимает состояние autoplay-lock. Файлы ограничены 12 МБ для PNG и 20 МБ для аудио; при переполнении IndexedDB приложение показывает ошибку и продолжает работу.
